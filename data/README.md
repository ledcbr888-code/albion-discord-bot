# AVA local map data

`ava-roadinator-maps.json` is a reduced local copy of the static map catalogue from
[obxd/roadinator-web](https://github.com/obxd/roadinator-web), originally published at
https://obxd.github.io/roadinator-web/.

The upstream repository is licensed under GPL-3.0. Keep the upstream attribution and
license obligations with this derived dataset. Update the file from upstream when the
map catalogue changes.

The data describes map components/markers. Combined resource component types are mapped
to their resource families by the AVA bot; this is a marker-based estimate and should not
be described as a guaranteed count of every individual gatherable node. Dungeon component
types are not classified as solo/group by this dataset and therefore are not guessed.
